## Stow

Use `stow --no-folding -t ~ <package>`

To restow a package after changes, use `stow -r --no-folding -t ~ <package>`

To unstow a package, use `stow -D -t ~ <package>`

Stow-compatible folders:

- `git`
- `jetbrains`
- `nvim`
- `starship`
- `tmux`
- `vim`
- `yazi`
- `zsh`
